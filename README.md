# 🔗 URL Shortener

A simple and efficient URL Shortener web application built using **Python and Flask**.  
The application converts long URLs into short, easy-to-share links and redirects users to the original URL.

## 🚀 Live Demo

🔗 https://codealpha-urlshortener-c39e.onrender.com

## 📌 Features

- Shorten long URLs into compact links
- Redirect short URLs to their original destination
- Simple and user-friendly interface
- REST-style backend using Flask
- URL validation
- Unique short URL generation
- Lightweight and easy to deploy
